# Initial Concept

PixelKeep Refactor (PWA): A secure, local-first note and quest management app with a retro 8-bit pixel-art aesthetic.

# Product Guide: PixelKeep

## Vision
PixelKeep is a secure, local-first Progressive Web App (PWA) designed for individuals who value both data sovereignty and a distinct aesthetic. It merges the utility of a modern productivity tool with the charming, nostalgic vibe of 8-bit retro gaming.

## Target Audience
- **Privacy-Conscious Users:** People who want to ensure their personal notes and tasks are never stored on a third-party server and remain fully encrypted.
- **Retro Enthusiasts:** Users who are drawn to pixel-art aesthetics and want a productive workspace that feels like a classic RPG.
- **Efficiency Seekers:** Individuals looking for a fast, offline-capable tool that works seamlessly across devices without the lag of cloud synchronization.

## Core Goals
- **Absolute Privacy:** Implement robust client-side AES-256 encryption so that data is only readable by the owner.
- **Immersive UX:** Deliver a unique user experience through pixel-perfect design, custom fonts, and game-inspired terminology (e.g., "Quest Log", "Scribe Scroll").
- **Reliable Performance:** Build an offline-first architecture using IndexedDB to ensure the app is always available and incredibly responsive.

## Key Features
- **Secure Scribing (Notes):** Rich text editor supporting bold, italics, and lists, plus the ability to embed images and audio recordings.
- **Quest Log (Tasks):** A dedicated task management system with support for due dates, locations, collaborators, and a customizable alarm system.
- **Tactile Organization:** Drag-and-drop reordering of notes and a hierarchical folder system for deep categorization.
- **Deep Customization:** Interchangeable themes (Standard vs. Pixel), font selection (including the 'Exo' font), and UI scaling to suit various screen sizes.
- **Seamless Portability:** Export and import functionality (compatible with legacy formats) to ensure data can be moved or backed up easily.
